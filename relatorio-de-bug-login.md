# Projeto 02 – Relatório de Bug: Login

**Tipo:** Bug simulado para fins de estudo.

## 1. Identificação do problema

**ID:** BUG001

**Título:** Sistema permite login com senha incorreta.

**Funcionalidade:** Tela de login.

**Severidade:** Alta (simulada).

## 2. Descrição

Durante a simulação de um teste de login, foi considerado um comportamento em que o sistema permite o acesso do usuário mesmo após informar uma senha incorreta.

## 3. Passos para reproduzir

1. Acessar a tela de login.
2. Informar um e-mail cadastrado.
3. Digitar uma senha incorreta.
4. Clicar no botão Entrar.

## 4. Resultado esperado

O sistema deve impedir o acesso e apresentar uma mensagem informando que a senha está incorreta.

## 5. Resultado obtido

No cenário hipotético, o sistema permite o acesso mesmo com a senha incorreta.

## 6. Impacto

Esse comportamento pode comprometer a segurança das contas dos usuários.

## 7. Status

Não executado em sistema real. Exemplo hipotético criado para praticar a documentação de bugs.

## 8. Observação

Este relatório demonstra como registrar e comunicar uma possível falha para a equipe de desenvolvimento.

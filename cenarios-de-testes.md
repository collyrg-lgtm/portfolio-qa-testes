# Projeto 03 – Cenários de Teste de Loja Virtual

**Tipo:** Exercício prático simulado.

## Objetivo

Identificar situações que precisam ser verificadas durante a utilização de uma loja virtual.

## Cenário 01 – Cadastro de usuário

Verificar se o sistema permite cadastrar novos usuários corretamente.

Casos relacionados:
- Cadastro com dados válidos.
- Cadastro com e-mail inválido.
- Cadastro sem preencher campos obrigatórios.
- Cadastro com e-mail já existente.

## Cenário 02 – Login

Verificar se o usuário consegue acessar sua conta.

Casos relacionados:
- Login com dados corretos.
- Login com senha incorreta.
- Login com e-mail não cadastrado.
- Login com campos vazios.

## Cenário 03 – Carrinho de compras

Verificar se os produtos são adicionados corretamente ao carrinho.

Casos relacionados:
- Adicionar um produto ao carrinho.
- Adicionar mais de um produto.
- Alterar a quantidade de produtos.
- Remover um produto do carrinho.

## Cenário 04 – Finalização de compra

Verificar se o processo de compra funciona corretamente.

Casos relacionados:
- Finalizar compra com dados válidos.
- Tentar finalizar compra sem endereço.
- Tentar finalizar compra sem selecionar pagamento.
- Verificar o resumo do pedido.

## Conclusão

Os cenários foram elaborados para identificar diferentes situações de uso de uma loja virtual e orientar a criação de casos de testes

**Observação:** Cenários hipotéticos, elaborados para fins de aprendizagem. Não foram executados em uma aplicação real.
